# include/psyq

PsyQ 3.7 SDK headers, one lowercase copy each, copied unmodified from the `INCLUDE/` tree of
`psyq-370.7z` (sha256 `9b3955ca74915a3e3b3eb18cf4fcf2210e75cac6985cb9a2ff90df8332e910e1`, see
`tools/psyq.sh`). The folder holds every header of that tree. Line endings are LF. Do not edit a
header; declarations the game needs beyond these belong in `include/psx/psyq.h`, the one barrel that
includes the SDK libraries.
