# Security

Report a vulnerability privately: open the repository's Security tab and choose
[Report a vulnerability](https://github.com/raulcorreia7/bof3-decomp/security/advisories/new).
Do not open a public issue for it. Include the affected file or command and the steps to reproduce.

The project is a decompilation and its build scripts. Reports about the scripts in `tools/` and
`bin/` (unsafe downloads, unchecked paths, command injection) are in scope.
